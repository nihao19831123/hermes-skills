适用：已有 ABM/仿真引擎（阶段 1–2 已交付）要做「可信度三件套 + 接进平台 + 进报告」这一类收口工作。
本文件只记录**踩过并已验证**的东西。

---

## 1. ⚠️ 最大的坑：首年增量被丢弃 →「5 年方案只有 4 年效果」

现象：分年表首行全是 0（`2026 +0`、累计 0），报告/前端看着像 bug；被判「说 5 年为什么首年是 0」会答不上来；
且与老引擎「5 年 = 5 次释放」**口径不可比**（互证、ABC 对比全部受影响）。

根因（阶段 1 埋下的）：主循环里写了

```python
d = (p_self - p_prev[i]) * visit_pot if t else 0.0    # 注释：「第 0 年为基期不计」
```

而设计伪代码是 `for t in range(years): inc, share = ChoiceModel.draw(agents, env, rng)`——**首年就该算增量**。

修法：去掉 `if t else 0.0`，`p_{−1}` 取基期 p0。**改完必须递增 `ALGO_VERSION`**（本项目 1.0.0 → 1.1.0），
否则：结果库 `biz_key = sha256(params+seed+algo+data_version)` 去重 → 同参数直接返回**旧版结果**，
自检里的「落库可回放（参数与关键值一致）」会突然 FAIL，且报错信息完全指不到真因（本项目实测，排查花了 2 步）。

变更幅度参考（心内科 +30%/5 年）：P50 累计新增门诊 54,604 → 56,238（+3.0%）；分年表首年 0 → +1,706。

## 2. 敏感性分析：判据必须先实测再定，别照抄设计里的「直觉方向」

设计初版判据：「距离权重 β_d 上调 → 远街道增量下降、近街道上升」。**实测弹性恒为 0.000，方向检查必 FAIL**。
不要据此改模型（会破坏已验收的引擎）——先用差分对拍证明实现无误（见 §4），再查机理：

- **基期锚定**：`u_out = ln(e_s(1−p0)/p0 − e_c)` 使 P(我院) 严格等于真实基线份额 p0，
  于是战略响应只依赖 p0 与战略乘子：`p = p0·m / (p0·m + (1−p0))`。**β_d / β_lo / β_tier 只进基期效用 ⇒ 对增量弹性恒 0。**
  → 这是**结构性推论，弹性为 0 即锚定成立**；不为 0 反而说明锚定被破坏。可以直接写进答辩（说明模型不是随手拍）。
- 空间梯度实际由 **距离衰减常数 d0** 与**远郊权重下限 `max(w_near, 0.15)`** 决定：远郊街道常触及下限 ⇒ d0 主要改变近端。
  实测 d0 +20%：近端人均 +4% 量级、远郊 +1% ⇒ 远/近端比值不升反略降（与设计预期相反）→ 作为 `flags` 如实标注 + 给 A/B 选项，不擅自改模型。

**可用的判据集（本项目最终 10 项，全部 PASS）**：
β_sp↑→目标专科人均增量↑、β_sp↑→总量↑、β_cap↑→总量↑、β_al↑→远郊人均↑（专科场景）、
β_al↑→远/近端比值↑（结构向外扩散）、β_al↑→远郊人均↑（医联体场景）、activation↑→总量↑、
magnitude 单调↑、**基期锚定权重弹性恒 0**、主指标区间 P5≤P50≤P95。

**参数分组（汇报时好用）**：A 战略通道权重 β_sp/β_cap/β_al（弹性 0.17–0.39）｜B 基期锚定权重 β_d/β_lo/β_tier（恒 0）｜
C 结构参数 d0/activation/k/spill_keep（0–0.28）｜D 对照项 magnitude（弹性 **1.10**，远高于所有权重）。
→ 结论句：**「调权重不如调强度」**：权重决定分布与结构，强度决定总量。

## 3. 度量坑：不同变体命中不同街道集 → 人均指标不可比

`street_effects` 只收录「有非零净增/迁移」的街道 → 变体的街道集不同（本次 7 街道 vs 10 街道），
人均指标在变体间**没有可比性**（一度得出「β_al↑ 让远郊下降」的错误结论）。

修法：让引擎额外输出**全街道平滑口径**（本项目 `interval.streets_meta`，134 行：
`name/district/d_km/lng/lat/agents/opd_cum/opd_last/p0`，不过滤零增量街道），
敏感性/空间梯度分析一律用它 + **固定街道集与固定分母**（分母取基准场景的 `agents`）。属新增字段，不影响既有字段的零回归。

**同种子纪律**：所有变体与基准共用同一个 `seed`（不是参数派生种子），否则变体差异里混入蒙特卡洛噪声，
弹性会漂、方向检查会假 FAIL。

## 4. 重构已有引擎时的零回归三件套（强烈建议固化为流程）

1. **基线哈希（改之前先存）**：固定一组参数 + `want_trace=True`，存 `interval`/`trace` 的 sha256、seed、n_agents。
   改完用**固定种子**重算比对——注意两个坑：
   - `data_version` 基于业务数据文件体积+修改时间；**一旦平台任何端点写过业务库（如老引擎 POST /run），
     data_version 与派生种子立刻变化**，结果自然不同（这是设计预期，不是回归）。比对时把 `data_version` 归一化回基线值。
   - 剔掉你**有意新增**的字段（如 `streets_meta`/`agents`）再哈希；别把新增字段当成回归。
   - 我犯过的错：只从新结果里 pop 掉字段再哈希，却忘了归档的旧哈希里**含着**该字段 → 假报「回归」。
2. **差分对拍脚本**（比看哈希更硬，且能证明"纯重构"）：把**改动前的内联公式逐字抄一份**成 `legacy_loop()`，
   与重构后的 `_agent_step()` 在多个场景（三类动作 × 三种份额口径 × 全域/选区 × 不同密度）逐一对比
   `p_self`/`p_comp` **浮点全等**（`max abs diff == 0.0`）+ **逐年选择串逐位相同**。
   本项目 6 场景全 PASS，才敢改判据。
3. **自检项数递增**：每个阶段往 `--selftest` 里加一条可复跑的判据（本项目 9 → 10 → 11 条：
   新增第 11 条「个体决策卡逐年选择 = trace 逐位相同 + 概率三分量自洽」）。

## 5. 接口落地形态（老系统"只增不减"）

- **独立路由文件**：新端点全放 `backend/agent_api.py`（`APIRouter(prefix=...)`），`app.py` 只加 2 行
  （`import agent_api` + `app.include_router(...)`）→ 老端点与前端页面零改动，diff 极小好审。
- **精度档映射**（设计 §11 的 fast/standard/full → 引擎实参）：`fast = runs 20 / density 0.5`（1,318 个智能体）、
  `standard = 50 / 1.0`（2,635）、`full = 200 / 2.0`（5,202）。响应里回传精度档中文说明，报告直接引用。
- **trace 恒取第 0 轮**：`trace` 只由 run 0 的随机流产生，**与 runs 无关** → 端点内部强制 `runs=1`，
  0.12s / 110KB（2,635 个体 × 5 年）；实测体积随密度：0.5/1.0/2.0/4.5 → 58.7 / 107.4 / 202.1 / 384.3 KB（预算 ≤400KB）。
- **内存缓存**（演示保命）：同参数 `/run` 二次调用 0.01s；敏感性（13 次推演、runs=12 实测 16s）加缓存后 0s。
  Key 里必须带 `ALGO_VERSION` 与 delta/runs。
- **个体级接口不落库**：`GET /agent?run_id=&agent_id=&year=` 用「同参数 + 同种子」复算（`agent_breakdown()` 复用
  `_prepare()`/`_agent_step()` 与**同一随机数消费顺序**，含 `streets` 选区时「不消费随机数」的分支也要照抄），
  并返回 `contrib{base,sp,cap,al}` 效用分量给个体决策卡。自检里断言「与 trace 逐年选择逐位相同」。
- **参数兼容**：`{"params": {...}}` 与扁平键都要收（前端两种传法都有）。

## 6. 报告集成（加一节而不动老报告）

- **章节动态重编号**：`_single()` 里 `if payload.get("agent_sim"):` 才插入新节，并把后续章节号 +1
  （六 智能体推演 / 七 AI 建议 / 八 口径）；**不传时输出与原来逐字一致**（老路径零风险）。
- 新节 7 小节：① 可复算信息（参数快照/种子/算法版本/数据版本/精度档）② 区间 P5–P95 ③ 分年表 ④ 重点街道 TOP8
  ⑤ 敏感性弹性表 + 方向自检 + **flags 以风险块呈现** ⑥ 回测误差表（全量，不裁剪）⑦ **口径声明**（合成智能体、非真实患者、
  与老引擎量级不可并列、大模型不参与计算）。
- 报告生成接口只加一处透传（`if req.get("agent_sim"): result["agent_sim"]=...`），不传时行为不变。
- **浏览器客观验收**（比肉眼可靠）：`file://` 打开生成的 HTML，用 JS 断言
  `h2.sec` 章节序列 == 一…八、表格数、`table.scrollWidth <= body.clientWidth`（横向溢出 0）、
  flags 是否渲染成 `.risk` 块、指定表首行是否非零（本次就是靠这条抓出「首年 0」）。
