## 三、五个\"看起来对其实错\"的建模 bug（按此顺序自查）

### 1. 新增口径：只算增量，不算\"所有选择我院的人\"
- 错法：每个选择我院的智能体每年都贡献 `weight × visit_base` → 每年重复计入基线总量。
- 症状：第一年就撞满容量；**所有场景的 P5/P50/P95 退化成同一个数**（区间彻底失效）；分年增量无意义。
- 正法：`d = (P_self,t − P_self,t−1) × weight × 人均门诊次数`（期望增量，平滑可加），或离散口径下 `0/2→1 计正、1→0/2 计负`；第 0 年 = 基期，不计增量；负增长直接释放容量（`take = min(pot, avail) if pot>0 else pot`；`spill = max(0, pot−take) × 留存系数`）。

### 2. 锚定只在基期做一次
- 错法：每年用**当年**的效用重解外部选项效用，使 P(我院) 回到基线 → 战略效果每年被\"校准掉\"。
- 症状：所有科室增量都是负的（图上看不出战略有效），而分年增量却是正的（两条口径自相矛盾）。
- 正法：抽样阶段一次性算 `u_self0 / u_comp / u_out` 并缓存到智能体上；逐年只在 `u_self0` 上叠加战略项 `β_sp·L·d_s + β_cap·L·d_c + β_al·L·d_a`。

### 3. 锚定代数（最隐蔽）
- 求 `e_o` 使 `P(我院) = e_s/(e_s+e_c+e_o) = r`：`e_o = e_s(1−r)/r − e_c`。
- 错法：`e_o = (e_s+e_c)(1−r)/r` → 基期概率只有目标值的 ~1/2（实测 u_self0=2.348, u_comp=2.471, r=0.02 → p=0.0095）。
- 自检法：抽样后对前几个智能体打印 `u_self0 / u_comp / u_out / p0 / p_self`，p_self 必须 ≈ p0；再打印各年 `p_self` 均值序列，基期后应单调上升。

### 4. 汇总字段必须整体取\"同一轮代表性运行\"
- 错法：对 `net / from_comp / from_out / lost / dept_net / years` **各自取分位点** → 导出的数字彼此不再满足恒等式（实测 134 街道里 49 个 `net ≠ 转来+激活−流失`）。
- 正法：选一轮代表性运行（如 `self_last` 中位数那一轮），其 `street_effects / dept_net / years` 整体导出，恒等式按构造成立；不确定性另附 `net_p5 / net_p95`（跨轮）与 `metrics{P5,P50,P95}`。
- **理由**：份额转移瀑布图的\"自洽核对行\"是答辩最硬的证据，导出数据必须自己就能对上。

### 5. 基线渗透率必须由真实数据反解
- 正法：`p0_s = 街道真实门诊量 ÷ (人口 × 人均年门诊次数)`，`potential = 人口 × 人均年门诊次数`；于是 `Σ p0×potential = Σ 街道门诊量`，与医院真实门诊/容量口径自洽。
- 错法：用\"门诊/人口\"的**分位数**映射成 p0（原型做法）→ 模型总量与真实门诊量、容量口径脱节，容量永远压不满。
- 由此得到必须交给用户拍板的**口径分歧**（见下）。

## 四、口径分歧：原型锚定值 ≠ 市场份额（必须让用户拍板）

| 口径 | 分母 | 我院基线占比（**2026-09-19 实测，覆盖此前预估**） | 蜂群观感 | 风险 |
|---|---|---|---|---|
| A 全市场（真实份额） | 全市潜在门诊需求 | **均值 2.13%**（总量口径 0.63%） | 几乎全灰橙 | 最低 |
| B 竞争圈层 | 我院 + 最近三级竞争医院合计门诊量 | **均值 3.7%**（原预估 30–50%，错） | 依然以灰橙为主 | 低，**必须画面常驻标注分母** |
| C 专科需求池 | 该专科潜在就诊人次 | **与 A 等价（退化，不可用）** | — | 现有数据只有"我院科室结构"、没有"居民专科需求结构"，分子分母同比例缩放 → 无法区分；属**数据缺口** |

**为什么 B 远低于预估**：各街道"最近的三级医院"多是大三甲（门诊量与我院同级），按距离衰减分摊后仍远大于我院在该街道的门诊量 → 街道级"我院 vs 最近竞争医院"的份额本来就是个位数。

**决策方拍板（2026-09-19）：A + B** —— 主口径用 **B 竞争圈层**（画面常驻标注分母），报告/材料中另附 **A 全市场真实份额** 做交叉说明；`share_basis` 参数（contested | city | dept_pool）与阶段 2 一并实装。

原型 v0.7 显示的"基线 51% 选择我院"是**分位数可视化锚定**，不是市场份额——**不能进任何汇报材料**。

**由此推出的可视化结论（重要）**：无论 A 还是 B，真实占比都是**个位数百分比**，"全屏大面积变绿"在真实口径下不存在。蜂群呈现三选一（2026-09-19 已提交用户待选）：① **焦点口径**＝默认只显示"被战略触动的个体"（|Δp| 超阈值，界面标注"仅显示受战略影响人群 X 个 / 全部 Y 个"，其余极淡色作背景层）；② **双层画布**＝底层全量真实份额 + 上层被触动人群高亮层；③ 蜂群降为"机制示意"，说服力交给 人次/号源/床位/分街道/分科室/份额转移 等绝对量指标。
